# Security Policy

## Supported Versions

Security updates are provided for the following versions of `marionette-tg`:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

We recommend always running the latest released version from
[PyPI](https://pypi.org/project/marionette-tg/).

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

This project uses GitHub's **private vulnerability reporting**. To report a
vulnerability privately:

1. Go to the
   [Security advisories page](https://github.com/marionette-tg/marionette/security/advisories/new).
2. Click **Report a vulnerability**.
3. Provide as much detail as you can:
   - a description of the issue and its impact,
   - the affected version(s),
   - steps to reproduce or a proof of concept,
   - any suggested remediation.

You can also reach this form from the repository's **Security** tab →
**Report a vulnerability**.

### What to expect

- We aim to acknowledge new reports within **7 days**.
- We will keep you informed as we investigate and work on a fix.
- Once a fix is available, we will coordinate disclosure and credit you in the
  advisory unless you prefer to remain anonymous.

Thank you for helping keep `marionette-tg` and its users safe.
